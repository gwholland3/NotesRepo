# My Personal Notes

This repo contains my public notes, which are written in Markdown files. You can find them in the `pages/` directory.

I use [Logseq](https://logseq.com/) to view and edit my notes locally, and I sync them across multiple devices using [Git](https://git-scm.com/). I've enabled the "Enable Git auto commit" and "Git commit on window close" settings in the Logseq desktop apps to make the Git experience smoother, and I've used macOS Shortcuts to add keyboard shortcuts so I can pull or push manually as well. Integrating Git with the iOS Logseq app was trickier, but I got it working with a combination of these three guides/resources:

1. <https://github.com/charliie-dev/Logseq-Git-Sync-101/wiki/For-iOS-iPadOS-users-(a-Shell,-Deprecated)>
1. <https://forum.obsidian.md/t/mobile-automatic-sync-with-github-on-ios-for-free-via-a-shell/46150> (written for Obsidian but mostly applies to Logseq too)
1. <https://bianshen00009.gitbook.io/a-guide-to-a-shell/basic-tutorials/configure-lg2-for-version-controlling?q=shortcut#ssh-configuration>

The notes are hosted by GitHub Pages at <https://gwholland3.github.io/NotesRepo/>. The website files are generated by [`publish-spa`](https://github.com/logseq/publish-spa) through GitHub Actions, and they are regenerated automatically every time I push changes to the Markdown source files.
