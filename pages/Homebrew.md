The missing package manager for macOS.

### Resources
- Main website: [https://brew.sh/](https://brew.sh/)Official documentation: [https://docs.brew.sh/](https://docs.brew.sh/)GitHub organization: [https://github.com/Homebrew](https://github.com/Homebrew)
### Terminology
- Tap: repository, aka bucket of software
- Cask: graphical software package

## Common Operations

### List all installed formula and casks that depend on a formula
`brew uses --installed <formula>`


## Taps
Taps are Homebrew’s name for remote repositories, from which you can install software.
