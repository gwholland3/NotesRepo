Neat tricks to remember:
- Hold CMD+OPTION while dragging to highlight a rectangular area
- Press CMD+SHIFT+. to open the "Composer", which serves as a scratchpad for editing a command before submitting it to the shell's stdin

Documentation for things I care about:
- Status Bar: [https://iterm2.com/documentation-status-bar.html](https://iterm2.com/documentation-status-bar.html)
## Color Scheme
There are a bunch of color schemes here: [https://github.com/mbadolato/iTerm2-Color-Schemes](https://github.com/mbadolato/iTerm2-Color-Schemes)
To import the "Homebrew" color scheme that the macOS Terminal app uses, I can run this from an iTerm session:

```
curl -O https://raw.githubusercontent.com/mbadolato/iTerm2-Color-Schemes/master/schemes/Homebrew.itermcolors && open Homebrew.itermcolors

```
