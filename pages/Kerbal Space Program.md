Things To Remember:
- General:
	- Toggle UI visibility: F2
	- Quicksave: F5
	- Quickload: F9
	- Open debug menu: Alt + F12
	- Toggle staging lock: Alt + L
- Map Mode:
	- Double click an object in map mode to focus view on it
- Vehicle Control:
	- Toggle precision mode: CAPS LOCK
