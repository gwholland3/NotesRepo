- # Keyboard Shortcuts
	- View keyboard shortcuts: (no-edit) `g``s`
	- Undo: `Cmd+z`
	  :LOGBOOK:
	  CLOCK: [2026-08-29 Sat 19:21:43]--[2026-08-29 Sat 19:21:44] =>  00:00:01
	  :END:
	- Select parent: `Cmd+a`
	- Select all blocks: `Cmd+Shift+a`
	- Exit edit mode: (edit) `Esc`
	- Follow link under cursor: (edit) `Cmd+o`
	- Open Logseq link in right sidebar: (edit) `Cmd+Shift+o`
	- Move up: `Up`
	- Move down: `Down`
	- Enter edit mode at start of block: (no-edit) `Left`
	- Enter edit mode at end of block: (no-edit) `Right`
	- Zoom into block: (edit) `Cmd+.`
	- Zoom out of block: (edit) `Cmd+,`
	- Collapse children blocks: `Cmd+Up`
	- Expand children blocks: `Cmd+Down`
	- Toggle current block collapse: `Cmd+;`
	- Toggle all blocks collapse: (no-edit) `t``o`
	- Move block up: `Cmd+Shift+Up`
	- Move block down: `Cmd+Shift+Down`
	- Search on current page: `Cmd+Shift+k`
	- Activate command palette: `Cmd+Shift+p`
	- Go to graph view: (no-edit) `g``g`
	- Go to settings: (no-edit) `t``s`
	- Toggle help overlay: (no-edit) `?`
