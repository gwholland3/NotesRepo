Good Formula Functions:
- [VLOOKUP](https://support.google.com/docs/answer/3093318): perform a lookup in a lookup table
- [MAP](https://support.google.com/docs/answer/12568985): apply a mapping function to an array
- [LAMBDA](https://support.google.com/docs/answer/12508718): create a lambda function, for use with MAP
- [SEQUENCE](https://support.google.com/docs/answer/9368244): generate a sequence of numbers
- [REDUCE](https://support.google.com/docs/answer/12568597): perform a reduction on an array
