- # Diagrams
	- Circuits are depicted using diagrams: [Wikipedia](https://en.wikipedia.org/wiki/Circuit_diagram)
	- See [here](https://en.wikipedia.org/wiki/Circuit_diagram#/media/File:Circuit_elements.svg) for some common symbols. Ones that I use regularly:
		- Resistor: zigzag
		- Diode: triangle pointing into a perpendicular line
			- Used to represent an LED, for example, since LEDs (Light Emitting Diode) are diodes
		- Ground: a series of parallel lines getting smaller
- # Circuit Boards
	- PCB = Printed Circuit Board
		- Good free software for designing PCBs: [KiCad](https://www.kicad.org/)
	- PCBA = Printed Circuit Board Assembly
	- FPCB = Flexible Printed Circuit Board (think LED light strip)
